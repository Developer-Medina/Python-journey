# 🐍 Python Journey: De Java para Automação & Dados

Bem-vindo ao meu repositório de estudos e prática em Python.

Este espaço documenta minha transição técnica e expansão de stack. Como desenvolvedor com base sólida em **Java (Spring Boot)**, utilizo este repositório para adaptar minha lógica de programação estritamente tipada para a flexibilidade do Python, focando em scripts utilitários, automação de tarefas e análise de dados.

## 🎯 Objetivo
Aplicar conceitos de Engenharia de Software (Clean Code, Tratamento de Exceções e Modularização) em scripts Python, indo além da sintaxe básica e focando em soluções robustas para problemas reais de **Troubleshooting** e **Sustentação**.

## 📂 Estrutura do Projeto

A organização segue minha trilha de aprendizado prático:

### 🔹 `/logic_warmup`
Exercícios de aquecimento e adaptação de sintaxe.
- Foco em: Estruturas condicionais, laços de repetição e conversão de tipos.
- **Destaque:** Implementação de tratamento de erros (`try/except`) e validação de inputs (blindagem de código) desde os primeiros scripts.

### 🔹 `/file_manipulation`
Manipulação de arquivos e I/O.
- Foco em: Leitura/Escrita de arquivos (`.txt`, `.csv`, `.json`) e parsing de dados.
- Aplicação real: Scripts futuros para análise de logs e extração de dados para troubleshooting.

### 🔹 `/automations`
Scripts voltados para produtividade e tarefas de sistema.
- Foco em: Automação de rotinas e interação com o Sistema Operacional.

### 🔹 `/resources`
Materiais de apoio, anotações técnicas e referências cruzadas (Java vs Python) que utilizo durante os estudos.
